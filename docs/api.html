API reference

Every server endpoint: the ConnectRPC services generated from packages/proto/, and the few REST routes that sit beside them.

Generated, do not edit. docs/api/ is exported from the running server's schema, and the pre-commit hook regenerates it whenever server or proto files are committed. To call endpoints, run the server and open http://127.0.0.1:8000/docs, which serves this same spec with "Try it out" enabled. A page opened from disk cannot call the server.

ConnectRPC methods are plain HTTP: POST /<package>.<Service>/<Method> with a JSON body. The raw spec is api/openapi.json, for tools such as Bruno or client generators.
